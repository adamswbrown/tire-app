Calculations Explained (Thresholds can be adjusted in Admin Settings)

Score Calculation

Each question's score is calculated based on the answer and weight:

Yes: Full weight value
Partial/Unsure: Half of weight value (rounded)
No: 0 points

Distribution Threshold (80%)

For each TIRE category, the distribution is calculated as:

Distribution = (Total Category Score / Total Possible Score) × 100%
Example:
Category has 5 questions, each with weight of 4:
• Total Possible Score = 20 points
• If actual score = 17 points
• Distribution = (17/20) × 100% = 85%
• Since 85% > 80% threshold, this category qualifies

Tiebreaker Threshold (3%)

Example:
If three categories exceed distribution threshold:
• Invest: 87%
• Tolerate: 85%
• Replace: 82%
Since all scores are within 3% of each other, tiebreaker is needed.
Tiebreaker Rules:
1. "Invest" is weighted more heavily in ties
2. Initial TIRE placement is considered
3. Manual selection may be required

Weight Scale (1-5)

1: Lowest importance
5: Highest importance
