1. Question Scoring

▼

Individual question scores form the foundation of the TIRE assessment. Each question's importance is weighted from 1-5, and the answer determines the final score.

Score Formula:
Question Score = Answer Value × Weight

Answer Values:
• Yes = 100% of weight
• Partial/Unsure = 50% of weight (rounded)
• No = 0% of weight
Example Calculations:
Question: "Is the system stable?" (Weight: 4)
• Yes = 4 points (4 × 100%)
• Partial = 2 points (4 × 50%)
• No = 0 points (4 × 0%)

Question: "Security compliance?" (Weight: 5)
• Yes = 5 points (5 × 100%)
• Partial = 2.5 points (5 × 50%)
• No = 0 points (5 × 0%)

2. Category Distribution

▼

Category distributions determine how well an application aligns with each TIRE category. Questions are grouped by their associated TIRE category (Tolerate, Invest, Replace, Eliminate), and their scores are aggregated.

Distribution Formula:
Distribution % = (Total Category Score / Maximum Possible Score) × 100

Score Components:
• Total Category Score = Sum of all question scores in category
• Maximum Possible Score = Sum of all weights in category
• Must meet/exceed threshold (80%) to qualify
Detailed Example:
Category "Invest" with 3 questions:
1. Weight 5, Answer: Yes = 5 points
2. Weight 3, Answer: Partial = 1.5 points
3. Weight 4, Answer: Yes = 4 points

Calculation:
• Total Score = 10.5 points (5 + 1.5 + 4)
• Maximum Possible = 12 points (5 + 3 + 4)
• Distribution = (10.5/12) × 100 = 87.5%

3. TIRE Placement Logic

▼

The final TIRE placement is determined through a systematic evaluation of category distributions and tiebreaker rules when necessary.

Placement Decision Tree:
1. Check all category distributions against threshold
2. Count qualifying categories (≥ threshold)
3. Apply placement rules based on count
4. Implement tiebreaker if needed
Placement Scenarios:
Scenario 1 - Clear Winner:
• Invest: 85% (Above threshold)
• Others: Below threshold
Result: Invest selected

Scenario 2 - Tiebreaker Needed:
• Invest: 87%
• Tolerate: 85%
• Replace: 82%
Result: Tiebreaker rules apply

Scenario 3 - Below Threshold:
• All categories < threshold
Result: "Below Threshold" status

4. Tiebreaker System

▼

The tiebreaker system resolves situations where multiple categories qualify and have similar distributions. It uses a combination of automatic rules and manual intervention when needed.

Tiebreaker Conditions:
• Multiple categories above threshold
• Score difference ≤ 3%

Resolution Priority:
1. Invest category bias (if Invest is tied)
2. Initial TIRE placement influence
3. Manual selection if still unresolved
Tiebreaker Example:
Scores:
• Invest: 83%
• Tolerate: 82%
• Replace: 81%

Resolution Process:
1. All within 3% → Tiebreaker needed
2. Invest present → Bias towards Invest
3. Check initial placement
4. If still tied → Manual selection

5. Weight Scale Guide

▼

Question weights reflect the relative importance and impact of different aspects of the application assessment.

Weight Scale (1-5):
5 - Critical: Direct business impact, essential functions
4 - High: Significant operational importance
3 - Medium: Moderate business impact
2 - Low: Limited business impact
1 - Minimal: Nice-to-have features
Weight Examples:
Weight 5: Security compliance, core business functions
Weight 4: Performance, user satisfaction
Weight 3: Integration capabilities, cost efficiency
Weight 2: Non-critical features, minor improvements
Weight 1: Cosmetic changes, optional enhancements
